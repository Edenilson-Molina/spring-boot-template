# Plantilla Spring Boot
Proyecto base para aplicaciones Spring Boot con Oracle, siguiendo buenas prácticas de arquitectura y desarrollo.

## Características principales:
- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- API REST (JSON)
- Base de datos Oracle (XE / XEPDB1)

## Ejecutar proyecto
```powershell
npm run build
mvn clean install
mvn spring-boot:run
```
